# Exercício 07 - Interpolação de Texto e Diretivas Vue.js

📅 **Entrega:** 15/10/2025 até às 23h59  
📚 Baseado nas aulas 1 e 2 do curso de Vue.js.

---

## 📌 Descrição
O objetivo deste exercício foi trabalhar com interpolação de texto no Vue.js e utilizar todas as diretivas aprendidas nas aulas, verificando as informações pela biblioteca Vetur no navegador.

---

## 🛠️ Funcionalidades

### Interpolação de Texto
- Exibição de dados usando `{{ }}`
- Dados dinâmicos: título, nome, curso, ano

### Diretivas Vue.js Utilizadas
- **v-if**: Exibe mensagem condicionalmente
- **v-show**: Mostra/oculta elementos
- **v-for**: Lista linguagens de programação
- **v-on** (@click): Evento de clique no botão
- **v-bind** (:src, :alt, :key): Vincula atributos HTML dinamicamente
- **v-model**: Ligação bidirecional de dados em inputs

---

## 🚀 Como executar

1. Abra o arquivo `index.html` em um navegador moderno
2. Ou use um servidor local:
```bash
# Com Python
python -m http.server 8000

# Com Node.js
npx serve
```

3. Acesse: http://localhost:8000

4. Para verificar com Vetur:
   - Instale a extensão Vetur no VS Code
   - Abra o projeto no VS Code
   - As informações serão destacadas e validadas automaticamente
